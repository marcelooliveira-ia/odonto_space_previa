# ODONTO SPACE — protótipo institucional

Site em Astro com páginas independentes, preparado para apresentação e evolução.

## Desenvolvimento
- Node.js 20+
- `npm install`
- `npm run dev`

## Build
- `npm run build`
- `npm run preview`

## Páginas
- /
- /implantes/
- /proteses/
- /ortodontia/
- /clinica/
- /contato/

## Antes da publicação definitiva
Validar endereço, telefone, horários, equipe, CRO/RT, especialidades e conteúdo clínico. Substituir imagens ilustrativas por imagens licenciadas/aprovadas e fotografias reais. Configurar domínio, Search Console, sitemap, analytics/tags e consentimento LGPD. O protótipo não representa garantia de posicionamento em buscadores.
